# Security

## Reporting a security problem in Gauntry

Please report security problems privately. **Do not post details in a public issue.**

1. Open the **Security** tab of this repository.
2. Choose **Report a vulnerability**.
3. Describe the problem, the Gauntry version (Setup, then About), your Android version and phone model, and the steps to reproduce it.

If you cannot use private reporting, write to the contact address given in the [Beta Testing End User License Agreement](EULA.md) and the [Privacy Policy](PRIVACY.md): hacken@hacken4u.com.

Do not include captured traffic, tokens, passwords, API keys, session cookies or anyone's personal data. If a detail like that is essential, say so in your report and wait to be asked.

## Scope

This covers the Gauntry app published in this repository's releases. Problems in a website or app you were testing with Gauntry should go to that site's or app's owner.
